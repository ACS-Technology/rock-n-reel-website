# Rock 'N Reel static site

This folder is ready to publish with GitHub Pages.

## Fastest GitHub Pages setup
1. Create a new GitHub repository.
2. Upload every file and folder from this directory to the repository root.
3. In GitHub: Settings -> Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a `github.io` URL.

## Custom domain
Once the GitHub Pages URL works, add your custom domain in:
Settings -> Pages -> Custom domain

GitHub will tell you which DNS records to add at your domain registrar.

## Files
- index.html — homepage
- style.css — page styling
- assets/rock-n-reel-logo.png — logo pulled from your published Webflow page
- favicon files — browser/tab and webclip icons
- 404.html — same landing page, useful for GitHub Pages
